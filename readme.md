# 📘 Panduan Penulisan & Kriteria Penilaian Tugas

Dokumen ini berisi pedoman struktur file dan detail kriteria penilaian untuk tugas mingguan. Harap dibaca dengan seksama sebelum mengedit file.


---

## ⚠️ PENTING: ATURAN STRUKTUR FILE

**JANGAN membuat folder/file berdasarkan Nama Kelompok.**

Dokumen **Google Docs** atau file submission harus dipisahkan dan dinamai berdasarkan **WEEK (Minggu)** materi tersebut dibahas.

**Contoh Struktur folder/file:**

**❌ SALAH:** `Folder Kelompok 1`, `Folder Kelompok 2`
**✅ BENAR:** `Folder Week 14`, `Folder Week 15`

---

## 🎯 Komposisi Penilaian (Total 100%)

Penilaian dibagi menjadi beberapa segmen dengan bobot sebagai berikut:

### 1. (Special) Role: Pembuat Template (Bobot: 10%)

*Hanya berlaku bagi kelompok yang bertugas menyusun template.*
Tugas utama adalah *formatting*, bukan mengisi materi.

* [ ] **Halaman Judul:** Sesuai standar format.
* [ ] **Daftar Isi:** Dibuat otomatis (bukan manual).
* [ ] **Penomoran Halaman:** Pastikan urutannya benar.
* [ ] **Kerapian:** Urutan sub-bab rapi dan konsisten.

### 2. (A) Definisi (Bobot: 30%)

Menjelaskan konsep dasar topik secara komprehensif.

* Mencakup definisi legal (jika ada) dan definisi teknis/akademis.

### 3. (B) Breakthrough (Bobot: 30%)

Menjelaskan terobosan teknologi terkait topik.

* Berisi inovasi/solusi teknologi (bukan sekadar studi kasus bencana).
* Menjelaskan kebaruan (*novelty*) dan dampaknya.

### 4. (C) Citation & Formatting (Bobot: 10%)

Ketertiban administrasi penulisan.

* [ ] **APA Style:** Sitasi menggunakan format APA.
* [ ] **Caption:** Semua tabel & gambar wajib memiliki caption.
* [ ] **Sumber:** Setiap gambar/tabel dari luar wajib mencantumkan sitasi.
* **Rumus:** 5% (APA) + 5% (Caption Gambar/Tabel) + 5% (Sitasi Sumber).

### 5. (D) Kualitas Konten (Bobot: 20%)

Kualitas dari gabungan Definisi (A) dan Breakthrough (B).

* [ ] Informasi akurat & memiliki referensi valid.
* [ ] Bahasa jelas dan mudah dipahami.
* [ ] Mengikuti pola **5W + 1H**.
* [ ] Tidak mengulang materi dari kelompok lain.
* [ ] Memiliki visual yang relevan.

---

## 🏆 Skema Nilai Maksimal (Max Score)

### 🔷 Kelompok Pembuat Template

Kesempatan mendapatkan nilai sempurna.
**Rumus:** Special (10%) + A (30%) + B (30%) + C (10%) + D (20%) = **100 (Nilai A)**

### 🔶 Kelompok Non-Template

Nilai dasar maksimal 90, dapat lebih besar jika konten luar biasa.
**Rumus Dasar:** A (30%) + B (30%) + C (10%) + D (20%) = **90 (Nilai A)**

**🌟 BONUS Exceptional Content:**
Jika kualitas konten (D) dinilai *Exceptional*, akan diberikan tambahan **10% dari poin (D)**.

## 📝 Checklist Sebelum Submit

* [ ] File sudah diletakkan di folder **Week** yang sesuai.
* [ ] Sitasi APA sudah benar.
* [ ] Setiap gambar/tabel memiliki caption & sumber.
* [ ] Penjelasan memenuhi **5W + 1H**.
* [ ] (Untuk Template Maker) Daftar isi otomatis & penomoran halaman benar.
